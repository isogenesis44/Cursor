How to use this in ChatGPT
  1. Download the job JSON (or one file per run if the whole file is too big to attach).
  2. In ChatGPT, start a new chat, attach the JSON and your style reference image, and paste the copied instructions.
  3. ChatGPT first replies with the image count and the run plan — no images yet.
  4. Turn it into a scheduled task (e.g. daily at 3am): "Continue the image job: do the next run".
  5. Make sure the Google Drive connector is on, so each image is saved as shot_0001.png, shot_0002.png… in the folder above.
  6. When done, download the Drive folder (it comes as a .zip) and drop it into step 3.
